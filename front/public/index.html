Вход и регистрация

Учётные записи обслуживаются сервером go_oauth2_server (прокси с этого API).

После входа: ROLE_SUPER_ADMIN / ROLE_ADMIN / ROLE_EDITOR → индексация карт; ROLE_USER → рекомендации локаций.

Рекомендации локаций

POST /locations/recommend с Bearer access token (если на сервере включён OAuth2 для API).

Индексация через Яндекс Карты (admin / super_admin / editor)
